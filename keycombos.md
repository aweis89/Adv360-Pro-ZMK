# Key Combinations

## Backlight Controls

- **Mod + Enter** - Toggle backlight on/off
- **Mod + Space** - Toggle RGB status light on/off

## Media Controls (Fn Layer)

### Playback Controls
- **Fn + Y** - Previous Track
- **Fn + U** - Play/Pause
- **Fn + I** - Next Track

### Volume Controls
- **Fn + K** - Mute
- **Fn + L** - Volume Down
- **Fn + ;** - Volume Up

### Brightness Controls
- **Fn + O** - Brightness Down
- **Fn + P** - Brightness Up

## Notes

- **Mod layer** is accessed by holding the innermost top key on either half of the keyboard
- **Fn layer** is accessed by holding the outermost bottom key on either thumb cluster
